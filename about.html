О проекте

Небольшой сайт из трёх страниц, про который и так все забудут.

Цель проекта

Понять структуру HTML-страницы, добавить оформление через CSS, оживить сайт с помощью JavaScript и выложить готовый результат в интернет.

Этапы работы

  1. Создание файлов Папка проекта, страницы index, about и contacts.
  2. Вёрстка на HTML Заголовки, абзацы, списки, навигация и картинка.
  3. Оформление в CSS Подключение style.css, цвета, шрифты, отступы.
  4. Интерактивность на JavaScript Подключение script.js, события, проверка формы, проекты из JSON.
  5. Публикация Репозиторий на GitHub и включённый GitHub Pages.

Использованные технологии

  • HTML5
  • CSS3
  • Flexbox
  • Grid
  • JavaScript
  • Bootstrap 5
  • JSON и fetch
  • GitHub Pages
